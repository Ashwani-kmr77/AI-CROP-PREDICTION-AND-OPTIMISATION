# AI Powered Crop Prediction and Optimization

## Overview
This is a full stack machine learning project that predicts the most suitable crop based on soil and environmental inputs. It also estimates yield, profit, irrigation needs, fertilizer advice, and alternative crops.

## Tech Stack
- React
- Node.js
- Express.js
- MongoDB
- Python
- FastAPI
- Scikit-learn

## Features
- User signup/login
- Farm management
- Crop prediction
- Yield estimation
- Profit estimation
- Fertilizer advice
- Irrigation advice
- Alternative crop recommendation
- Prediction history dashboard

## ML Model
- Random Forest Classifier for crop prediction
